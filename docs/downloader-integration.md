# 与延河课堂下载器配合使用

播放器负责在本机配对和播放课程视频。下载由独立项目完成：

- [BITNP/BIT_yanhe_download](https://github.com/BITNP/BIT_yanhe_download)：本项目配合使用的延河课堂下载器。
- [AuYang261/BIT_yanhe_download](https://github.com/AuYang261/BIT_yanhe_download)：下载器原作者的项目；其许可证署名为 `Copyright (c) 2023 AuYang261`。

本仓库不包含下载器源码、登录凭据、课程视频、下载记录或个人课程清单。使用者自行准备有权访问和保存的课程录像。

## 下载两种画面

1. 按下载器自己的 README 安装和登录。将下载器放在播放器仓库之外的独立文件夹中。
2. 下载同一课程、同一节次的两种信号：摄像头录像和电脑屏幕录像。两个信号共同构成播放器的一节课。
3. 确认两个 MP4 都能正常播放，再在播放器中配对。播放器支持字幕文件导入；字幕生成方式由使用者选择，可参考下载器的字幕生成功能。

上游不同界面的操作方式可能不同：原始命令行入口一次选择一种信号，其他界面可能支持多选。以所使用版本的说明为准。

## 接入播放器

上游常见的输出布局是两个独立目录，例如：

```text
output/
  示例课程-video/
    示例课程-示例教师-第1次课.mp4
  示例课程-screen/
    示例课程-示例教师-第1次课.mp4
```

两种信号的文件名应对应同一节课。不要把不同日期、不同节次的录像配成一对。

- 手动导入：分别把摄像头文件拖到“课堂 / 录像”，把屏幕文件拖到“PPT / 屏幕”。这不要求移动或改名视频文件。
- 自动课程库：复制 `config/courses.example.json` 为 `config/courses.json`，指定本地摄像头目录和屏幕目录。同名 MP4 会按文件名配成一节，无需先改成特定的课程编号格式。

例如，保留上游的两个兄弟目录，可以这样配置：

```json
{
  "data_root": "../../my-downloads/output",
  "courses": [
    {
      "id": "course-a",
      "name": "示例课程",
      "teacher": "",
      "camera_directory": "示例课程-video",
      "screen_directory": "示例课程-screen"
    }
  ]
}
```

`data_root` 的相对路径从 `config/courses.json` 所在文件夹计算；两个信号目录的相对路径从 `data_root` 计算。请把例子中的路径替换为自己的下载位置，`id` 只需在自己的课程配置中保持唯一。

也可以自行整理成同名文件配对的目录结构：

```text
课程资料/
  示例课程/
    01_课程介绍.mp4
    02_基础概念.mp4
    电脑屏幕/
      01_课程介绍.mp4
      02_基础概念.mp4
```

视频始终留在本机。公开仓库只提交程序及不含个人信息的配置示例，实际视频目录和个人配置不提交。

若两种画面有少量时间差，可在播放器中调整 PPT 偏移。切换画面不会重新导入文件；音频来源和画面布局可以分别选择。

## 登录信息与下载产物

下载器可能在本机保存 `auth.txt`、课程清单、日志、播放清单和临时片段。这些文件不属于播放器发行内容。不要把下载器工作目录整体复制进公开仓库，也不要把包含签名参数的播放链接放进 Issue 或截图。

播放器不需要读取下载器的登录信息。不要把 Token、Cookie 或身份认证码写进播放器配置。
