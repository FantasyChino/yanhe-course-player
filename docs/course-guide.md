# 课程准备指南

这份指南介绍在线找课与直接观看，以及下载后接入本地课程库的两种用法。登录由用户在自己的浏览器完成；播放器可使用本机登录凭据读取在线课程，也保留离线视频播放。

## 在线直接观看

1. 双击 `start-player.cmd` 或桌面快捷方式，在播放器切换到“在线课程”。
2. 查看登录状态。需要配置时，在自己的浏览器打开[延河课堂](https://www.yanhekt.cn/)并登录，再按[上游登录说明](https://github.com/BITNP/BIT_yanhe_download/blob/main/README.md#登录延河课堂)获取凭据；展开“配置登录凭据”，填入后点击“使用凭据”。播放器无需账号或密码，也不会替用户自动完成登录。
3. 输入课程名称搜索，结合结果中的教师与学期选择课程。需要时点击“加载更多课程”。
4. 在侧栏选择节次，点击播放，课堂与 PPT 信号便会按需加载，无需预先下载整门课。
5. 已知课程编号或链接时，也可以在“课程编号 / 链接”中直接打开。

界面只显示登录状态，不显示凭据内容。本机登录凭据仅在服务内存中保存，不写入浏览器 `localStorage`；失效后重新配置。启动服务时也可用 `--auth-file` 读取自己的凭据文件，示例见[README](../README.md#在线搜索与观看)。凭据文件请放在仓库外，勿提交到 GitHub。

在线播放需要联网，课程是否存在、有哪些信号以及是否可访问，都取决于平台返回的内容与自己的访问情况。若偏好保留本地视频，继续按下面的流程准备。

## 1. 查课程编号

可参考[课程编号表（腾讯文档）](https://docs.qq.com/sheet/DWkJqem5OWVF1Qmxq?tab=000001)查找课程编号。这份表格由外部维护；本项目只提供入口，不维护或复制表格内容。

拿到编号后，将下面示例地址中的 `63093` 替换成目标课程编号：

```text
https://www.yanhekt.cn/course/63093
```

请自行在[延河课堂](https://www.yanhekt.cn/)登录，再核对课程名称、教师和课节信息。这里使用的是 `/course/` 后的**课程编号**，与单节播放页面 `/session/` 后的编号不同。

课程不存在、平台暂不可用或访问受限时，请先确认编号和自己的访问情况。本播放器不能修复平台故障，也不提供额外的课程访问授权。

## 2. 用上游下载器准备两路视频

参考项目：[BITNP/BIT_yanhe_download](https://github.com/BITNP/BIT_yanhe_download)。

安装包、登录方式、任务创建和界面选项可能更新，具体操作请以[上游最新 README](https://github.com/BITNP/BIT_yanhe_download/blob/main/README.md)中的“使用：下载指定课程”“登录延河课堂”和 GUI 说明为准。

准备时需要：

1. 使用已核对的课程编号建立下载任务。
2. 按上游登录说明，在自己的电脑上提供下载所需的登录凭据。
3. 下载需要观看的课节，分别准备**摄像头录像**和**电脑屏幕**两路视频。

下载器与播放器在线模式分别使用自己提供的本机登录凭据；同频的本地视频模式不需要登录。请不要把 Token、密码或含凭据的配置提交到 GitHub。

下载器的网页 GUI 和命令行 GUI 是上游功能，与本项目的播放器页面不同。本项目不捆绑上游下载器程序；下载出错时请先查看上游的使用说明与已有问题。

## 3. 将视频接入本地课程库

课程库支持两种目录布局，任选一种即可。

**方式一：课堂目录内有 `电脑屏幕` 子目录。**

```text
视频根目录/
└─ 某门课程/
   ├─ 01_某节课.mp4
   ├─ 02_某节课.mp4
   └─ 电脑屏幕/
      ├─ 01_某节课.mp4
      └─ 02_某节课.mp4
```

使用课程配置的 `directory` 指向“某门课程”。课堂与 PPT 通过同名 MP4 配对。

**方式二：保留下载器的两个并列目录。**

```text
output/
├─ 某门课程-video/
│  └─ 01_某节课.mp4
└─ 某门课程-screen/
   └─ 01_某节课.mp4
```

将 `data_root` 指向 `output`，在课程项中设置 `camera_directory` 为 `某门课程-video`，`screen_directory` 为 `某门课程-screen`。无需移动或重命名文件；两路同名 MP4 会自动配对。

将 `config/courses.example.json` 复制为 `config/courses.json`，在 `courses` 中填写每门课的 `id`、`name`、`teacher` 与目录。`data_root` 若为相对路径，以配置文件所在目录为基准；`directory`、`camera_directory` 和 `screen_directory` 相对于 `data_root`。两种完整 JSON 示例见[项目 README](../README.md#视频怎样放)。

双击 `start-player.cmd`，在课程选择栏选择课程，再点侧边节次目录。播放器会载入可用的课堂和 PPT 视频；只有一路时，也可以先观看已有的视频。

不想整理目录时，可以直接点击“选择两个视频”，或将两路文件分别拖到“PPT / 屏幕”和“课堂 / 录像”。

## 4. 字幕和观看设置

- **字幕**：准备本地 `.srt` 或 `.vtt`，点击“导入字幕”或拖入。导入后可选字号、显示开关与时间来源。播放器不自动生成字幕。
- **声音**：在音频菜单选择课堂或 PPT。画面布局和声音来源相互独立。
- **对齐**：PPT 时间微调用于对齐两路视频；字幕的“延后”用于对齐字幕与所选视频时间。
- **全屏**：鼠标移到屏幕最下方显示选项；离开选项区后收起，按 `Esc` 退出。

完整功能、配置示例和快捷键见[项目 README](../README.md)。
