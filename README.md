# 同频 · 延河课堂双画面播放器

把 PPT 看清，把课堂听完整。

同频是一款在自己电脑上运行的双视频播放器。选择课程与节次，便可同时打开课堂录像和 PPT 屏幕视频；也可以直接拖入两个视频，随时切换双画面、只看 PPT 或只看课堂。

本项目专注于已下载视频的整理与播放。配合以下流程使用更方便：

**[课程编号参考表](https://docs.qq.com/sheet/DWkJqem5OWVF1Qmxq?tab=000001) → [延河课堂](https://www.yanhekt.cn/) → [BIT_yanhe_download](https://github.com/BITNP/BIT_yanhe_download) → 同频本地播放器。**

课程编号表由外部维护，本项目不维护、复制或分发其中的数据。课程查找、登录与下载步骤见[课程准备指南](docs/course-guide.md)。请自行登录延河课堂，并在自己的访问权限与课程使用约定范围内使用视频。

## 可以做什么

- **本地课程库**：选择课程，再点节次，自动配对课堂录像与同名 PPT 视频。
- **双画面同步播放**：共享播放、暂停和进度条，中途切换视图保留观看位置。
- **独立选择音频**：课堂音频、PPT 音频或静音，支持音量调节。
- **0.5× 至 3× 倍速**：两路视频一同变速，PPT 时间可单独微调。
- **沉浸全屏**：画面铺满，鼠标移到屏幕最下方唤出布局、音频、倍速和字幕选项；离开后自动收起。
- **本地字幕**：导入 SRT / VTT，调整开关、字号、提前或延后，并选择跟随课堂或 PPT 的时间。
- **观看进度**：浏览器保存每节课的观看位置、上次选择的课程与节次，以及播放偏好。
- **保留手动导入**：不配置课程库也能拖入视频，另可生成独立离线 HTML。

字幕需要自行准备和导入；本播放器不自动识别语音，也不会自动生成字幕。

## 开始使用

需要 **Windows、Python 3.10 或更新版本，以及 Chrome / Edge 等现代浏览器**。本地播放器与课程服务使用 Python 标准库，无需额外安装 Python 包。尚未安装 Python 时，可从 [Python 官网](https://www.python.org/downloads/)获取。

1. 下载或克隆本仓库，解压到一个固定文件夹。仓库不包含课程视频、字幕、账号、密码或登录凭据。
2. 准备已下载的课堂与屏幕 MP4，按下面的文件夹结构整理。
3. 将 `config/courses.example.json` 复制为同目录下的 `config/courses.json`，修改 `data_root` 和课程目录。
4. 双击 **`start-player.cmd`**。它会启动仅在本机使用的课程服务，并打开播放器。
5. 在“本地课程库”选择课程，点击目录中的节次，再点播放。

想从桌面直接进入，可在项目文件夹打开 PowerShell，运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install_shortcut.ps1
```

之后双击安装好的桌面快捷方式即可。移动项目文件夹后，请重新安装快捷方式。

## 视频怎样放

每门课一个文件夹。课堂 MP4 放在课程目录内，PPT MP4 放在其中的 `电脑屏幕` 文件夹中，**同一节课的两个文件名应完全一致**。

```text
课程视频/
├─ 电路分析基础/
│  ├─ 01_第一节.mp4
│  ├─ 02_第二节.mp4
│  └─ 电脑屏幕/
│     ├─ 01_第一节.mp4
│     └─ 02_第二节.mp4
└─ 概率论与数理统计/
   ├─ 01_第一节.mp4
   └─ 电脑屏幕/
      └─ 01_第一节.mp4
```

配置示例：

```json
{
  "data_root": "../videos",
  "courses": [
    {
      "id": "50206",
      "name": "电路分析基础",
      "teacher": "",
      "directory": "电路分析基础"
    },
    {
      "id": "50958",
      "name": "概率论与数理统计",
      "teacher": "",
      "directory": "概率论与数理统计"
    }
  ]
}
```

`data_root` 指向视频根目录：相对路径以 **`courses.json` 所在文件夹**为基准，因此此处 `../videos` 指项目根目录中的 `videos` 文件夹；也可以改成 `D:/课程视频` 等绝对路径。`directory` 相对于 `data_root`，指定课程的课堂目录，PPT 默认从其中的 `电脑屏幕` 子目录读取。

`id` 用于标识课程，`name` 和 `teacher` 用于显示。示例中的两门课只演示配置格式，不附带任何课程内容；请替换为自己的课程与目录。路径中使用 `/` 可以避免 JSON 中反斜杠转义的问题。

**已经用上游下载器下载，课堂与屏幕在两个并列文件夹中？** 无需重新整理。用 `camera_directory` 和 `screen_directory` 分别指定路径，它们也相对于 `data_root`。例如：

```json
{
  "data_root": "D:/下载器/output",
  "courses": [
    {
      "id": "50206",
      "name": "电路分析基础",
      "teacher": "",
      "camera_directory": "电路分析基础-video",
      "screen_directory": "电路分析基础-screen"
    }
  ]
}
```

这会将 `电路分析基础-video/01_第一节.mp4` 与 `电路分析基础-screen/01_第一节.mp4` 配成一节课。请按实际目录填写；两路 MP4 使用相同的文件名即可自动配对。也可以跳过配置，直接手动选择两个视频。

## 播放与同步

| 操作 | 用法 |
| --- | --- |
| 播放 / 暂停 | 点击播放按钮，或按空格 |
| 跳转 | 拖动进度条；左右方向键后退 / 前进 10 秒 |
| 切换画面 | `1` 双画面，`2` PPT，`3` 课堂 |
| 全屏 | 按 `F` 或点击全屏按钮；`Esc` 退出 |
| 全屏选项 | 鼠标移到屏幕最下方；`Tab` 可用键盘唤出 |
| 继续观看 | 切回课节后，点击出现的“继续上次”按钮 |

PPT 偏移 `+2` 秒表示：课堂到 10 秒时，PPT 显示第 12 秒的内容。`-2` 秒则显示第 8 秒。两路时长不同时，较短一路结束后停留在末帧，另一画面继续播放。

字幕延后 `+2` 秒表示：原本 10 秒出现的文字改在 12 秒出现；负数表示提前。字幕“跟随 PPT 时间”适合以 PPT 视频时间轴制作的字幕。

浏览器只在本机保存播放偏好和观看位置。更换浏览器、清理浏览器数据或使用不同的播放器地址，可能看不到原有记录。

## 不配置课程库也能用

直接打开 `dist/index.html`，点击“选择两个视频”或将文件拖进相应画面。字幕也可以点击导入或直接拖入。刷新页面后，需要重新选择手动导入的视频与字幕；课程库模式可按课程重新载入视频。

运行：

```powershell
python .\bundle_local.py
```

可生成把 HTML、CSS、JavaScript 合在一起的离线播放器。课程库依赖本机服务；直接以 `file://` 打开 HTML 时，会显示通过桌面快捷方式读取课程库的提示，手动导入仍可使用。

## 常见问题

**课程库没有出现，或提示从快捷方式打开。**
请双击 `start-player.cmd` 或桌面快捷方式。直接打开 HTML 时，浏览器不能替你扫描课程目录。

**找不到课程或课节。**
检查 `config/courses.json` 是否为有效 JSON，根目录与课程子目录是否存在，视频是否为 MP4。新增文件或调整目录后重新打开播放器。

**有课堂画面，没有 PPT。**
检查 `电脑屏幕` 子目录，以及两路 MP4 的文件名是否一致。尚未下载的信号需要先自行准备。

**画面正常但没有声音。**
检查音频来源、音量和浏览器标签页是否静音；选中的视频本身也需要包含音轨。切换视图不会自动切换音频来源。

**文件打不开。**
推荐 H.264 视频与 AAC 音频的 MP4。文件扩展名相同也可能使用不同编码，能否播放取决于浏览器支持。

## 项目结构与开发

```text
dist/                       播放器页面、样式与交互
local_server.py             本机课程索引与视频分段读取服务
launch_player.ps1           Windows 本机启动器
install_shortcut.ps1        安装桌面快捷方式
start-player.cmd            双击启动入口
bundle_local.py             生成独立离线 HTML
config/courses.example.json 课程配置示例
docs/course-guide.md        查找课程、准备下载与导入说明
```

本机课程服务默认地址为 `http://127.0.0.1:8767`，仅监听回环地址；视频从本机按需读取，不上传到远程服务器。播放器不需要延河课堂登录凭据。请勿向公开仓库、Issue 或截图中提交自己的 `courses.json`、课程视频、字幕或登录 Token。

`local_server.py` 默认读取 `config/courses.json`，尚未创建时回退到 `config/courses.example.json`。也可以指定另一份配置：

```powershell
python .\local_server.py --config .\config\courses.json
```

浏览器自动化验证请使用独立测试配置，并加 `--mute-audio` 强制静音，避免打扰正在使用电脑的人。

后端检查使用标准库测试，无需课程视频或登录凭据：

```powershell
python -m unittest discover -s tests -v
```

前端没有构建依赖。开发者也可用 `node --check dist/player.js` 检查语法。
